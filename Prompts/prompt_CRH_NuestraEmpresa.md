# 1) Design Kit de Portadas (Workexion)

## 1.1 Principio rector

> Neutral + moderno + adaptable + no invasivo para marca cliente

👉 Evitamos:

* Colores dominantes tipo branding fuerte (azul corporativo, rojo intenso)
* Estilos que compitan con identidad del cliente

👉 Buscamos:

* Estética SaaS moderna
* Versatilidad para cualquier industria

---

## 1.2 Paleta de colores (1 por sección)

| Sección          | Color           | Código    | Intención              |
| ---------------- | --------------- | --------- | ---------------------- |
| Quiénes Somos    | Gris profundo   | `#2F2F2F` | Institucional, neutral |
| Cultura          | Verde suave     | `#5BBFA3` | Humano, cercano        |
| Liderazgo        | Morado elegante | `#7A6FF0` | Estratégico, premium   |
| Impacto y Futuro | Naranja ámbar   | `#F5A623` | Innovación, energía    |

---

### Decisión clave

* Ningún color es dominante tipo “marca global”
* Todos funcionan como **overlay**, no fondo sólido

---

## 1.3 Tipografía (1 sola)

## **Inter (recomendado)**

**Uso:**

* Título: Bold
* Subtítulo: Medium

**Por qué:**

* Estándar en SaaS
* Alta legibilidad
* Neutral (no roba protagonismo)

---

## 1.4 Layout fijo (NO se negocia)

## Estructura de imagen 16:9 (1024 x 579 px)

```
[ Imagen base ]
[ Overlay color 25–35% ]

┌───────────────────────────────┐
│                               │
│   TÍTULO (izquierda)          │
│   Subtítulo opcional          │
│                               │
│                     (imagen)  │
└───────────────────────────────┘
```

---

## Reglas

* Texto alineado a la izquierda
* Máximo:

  * Título: 4–6 palabras
  * Subtítulo: 1 línea
* Zona derecha más visual
* Overlay SIEMPRE aplicado
